# Installing TSD Technologies 1.2.0

Requires SPT 4.1.6 and Anvil WebOverlay 1.12.0 or newer.

1. Close the game and SPT server. Back up your installation/settings.
2. Remove only `BepInEx/plugins/TsdTechnologies` and `SPT_Runtime/user/mods/TsdTechnologies` from the old Technologies installation.
3. If you participated in private testing, also remove `BepInEx/plugins/TsdTechnologies-AnimationPrototype` and `BepInEx/plugins/TsdTechnologies-DropPhysicsTest`.
4. Extract this ZIP into the SPT game root so its BepInEx and SPT_Runtime folders merge with yours.
5. Keep your Technologies configuration, wallpapers and separately installed Logistics 3.0.0. Do not install standalone Logistics 2.1.0 alongside Technologies.
6. Start the server and game. Carry the terminal in raid. Use your existing tablet key; fresh installations default to F9.

No user profile or configuration files are included in this package. The private F7 preview shortcut is retired. Tablet animation and handling sound controls are in the main Technologies F12 settings.
