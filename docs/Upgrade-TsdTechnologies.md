# TSD Technologies 1.2.1 installation

1. Close the game and SPT server. Back up the profile and tablet settings.
2. Extract this archive into the main SPT game folder beside EscapeFromTarkov.exe, merging BepInEx and SPT_Runtime and replacing existing Technologies program files.
3. Keep existing tablet configuration, wallpapers, player profiles and Logistics files. A configuration reset is not required for an existing 1.x installation.
4. Keep Anvil WebOverlay 1.12.0 or newer installed with the tablet's dependencies.
5. Start the server and game normally.

Do not extract only into SPT_Runtime. TSD Logistics is installed separately.
