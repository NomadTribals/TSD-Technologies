# TSD Technologies 1.4.0 — Maps & Minimap

- Maps now displays Satellite by Fums inside the TSD tablet. Satellite is an optional, separate installation; tested with Satellite 1.0.1.
- Optional live minimap in a matching graphite tablet casing. It follows the player during raids and remains click-through so movement and aiming work normally.
- Minimap size and position are adjustable in F12. Its marker visibility follows the full tablet map’s choices.
- Map preferences persist between game launches.
- M opens the tablet directly to Maps and closes it when Maps is already open. Change or disable the shortcut in F12 → Controls → MapToggleKey.
- Startup now defaults to once per game launch, including transitions from stash to raid. The previous once-per-raid behaviour remains available in F12 → Tablet Startup → BootFrequency.
- Missing Satellite installations show a requirement page with a link to Fums’ Forge listing.

Requires SPT 4.1.6 and Anvil WebOverlay 1.12.0 or newer. Satellite is required only for Maps and the minimap. TSD Messenger 1.0.0 and TSD Logistics 3.1.0 remain compatible; neither needs an update.

Special thanks to Fums for [Satellite](https://sp-mod.com/mod/3373/satellite), CC BY-NC 4.0, and to maschine for Anvil WebOverlay. Satellite’s code and map pack are not included in this archive.
